# Ambient Video Builder

## Версия с окном — для Windows

Открой двойным щелчком `start_builder.bat`. Появится окно: добавь видео, длинный фон (например, 30 минут прибоя), укажи длительность, разрешение и место сохранения, затем нажми «Собрать видео». Команды вводить не надо. По умолчанию выбраны **4K** и автоматический быстрый кодировщик: NVIDIA, Intel или AMD при наличии, иначе CPU.

По умолчанию включён режим **«Монтаж — обычные клипы»**. Он предназначен для Flow и Kling: каждый клип проигрывается только вперёд, без разворота и короткого loop. Программа делает два перемешанных круга, соединяет кадры спокойными переходами и повторяет уже весь большой блок до выбранной длительности.

В этом режиме включена галка **«Сохранять звук в сценах»**. Она оставляет локальные звуки, уже добавленные в CapCut: мурлыканье кота, треск дров, птиц. В раздел **«Фон на весь ролик»** добавляй одну длинную дорожку из банка звуков — например, прибой на все 30 минут. Программа смешивает её тише локальных эффектов. Не добавляй тот же прибой внутрь каждой сцены: иначе он будет повторяться и накладываться на себя.

Для такого запуска нужны две бесплатные установки один раз: [Python](https://www.python.org/downloads/windows/) (в установщике включи **Add Python to PATH**) и [FFmpeg](https://www.gyan.dev/ffmpeg/builds/). После скачивания FFmpeg добавь его папку `bin` в системный PATH. Это временный вариант до готового EXE.

В репозитории есть GitHub Action, которая собирает готовый единый `AmbientVideoBuilder.exe` вместе с FFmpeg. Его можно будет скачать из раздела **Actions → Build Windows application → Artifacts**, распаковать и запускать двойным щелчком — без Python и FFmpeg.

## Версия через Python

Собирает длинное MP4 из коротких видеоклипов. У каждого клипа создаётся цикл: его конец плавно переходит в начало, а следующий повтор продолжается после уже использованного начала. Между разными сценами есть отдельное растворение. Внешние записи звука зацикливаются и миксуются независимо от видео.

Длинные промежуточные сцены больше не рендерятся в отдельные файлы. Весь 30-минутный монтаж кодируется одним финальным проходом, а звук добавляется без повторного пережатия видео.

Нужны Python 3.10+ и FFmpeg/FFprobe в PATH.

## Быстрый запуск

```bash
python make_ambient_video.py --clips-dir ./clips --audio waves.wav fire.wav --output ambient_30min.mp4 --duration 30 --seed 42
```

Для 4K с автоматическим выбором GPU:

```bash
python make_ambient_video.py --clips-dir ./clips --audio waves.wav fire.wav --output ambient_4k.mp4 --duration 30 --width 3840 --height 2160 --encoder auto
```

Монтаж обычных AI-клипов без индивидуального зацикливания:

```bash
python make_ambient_video.py --clips-dir ./clips --audio waves.wav --output ambient_30min.mp4 --duration 30 --mode montage --transition calm --transition-duration 0.8 --montage-rounds 2
```

Сначала сделай превью (оно не создаёт 30-минутный файл):

```bash
python make_ambient_video.py --clips-dir ./clips --audio waves.wav --output ambient.mp4 --duration 30 --preview --seed 42
```

Превью получит имя `ambient_preview.mp4`. Оно показывает первые 20 секунд реального монтажного плана. Для спокойной проверки каждого исходника лучше сначала использовать один клип в отдельной папке.

Для намеренно немого видео:

```bash
python make_ambient_video.py --clips-dir ./clips --audio-mode silent --output silent.mp4 --duration 5
```

`--dry-run` проверит файлы и покажет план без рендера.

## Важные параметры

- `--crossfade 1` — переход внутри каждого короткого клипа.
- `--scene-crossfade 2` — переход между разными длинными сценами.
- `--audio-crossfade 2` — переход внутри фонового звука.
- `--min-seg 120 --max-seg 300` — длительность каждой сцены в секундах.
- `--scale-mode fit` — добавить чёрные поля при несовпадении пропорций; `fill` обрежет края.
- `--audio-gain -8 -14` — уровни для первого и второго аудиослоя в dB.
- `--keep-scene-audio` — сохранить звук, встроенный в исходные сцены, и смешать его с внешним фоном.
- `--scene-audio-gain 0` — уровень встроенного звука сцен в dB.
- `--encoder auto` — проверить NVIDIA NVENC, Intel Quick Sync и AMD AMF, затем автоматически перейти на CPU, если аппаратное кодирование недоступно.
- `--encoder cpu` — принудительно использовать `libx264`; `--cpu-preset fast` задаёт баланс скорости и качества.
- `--width 3840 --height 2160` — экспорт 4K; в окне 4K уже выбрано по умолчанию.
- `--mode montage` — проигрывать клипы вперёд и повторять большой монтажный блок; `loop` оставляет прежний режим.
- `--transition calm` — в основном мягкое растворение и редкая белая дымка; доступны также `fade`, `fadewhite` и `fadeblack`.
- `--transition-duration 0.8` — длительность монтажного перехода в секундах.

Рядом с итогом появляется `*_report.json` с seed и планом сцен. Повтор с тем же seed даёт тот же порядок.

## Ограничения этой версии

- Первый выпуск предназначен для SDR. HDR-клипы с iPhone лучше заранее перевести в SDR.
- При включённом `--keep-scene-audio` сцены должны уже содержать только локальные эффекты. Постоянный прибой/ветер оставляй внешней дорожкой на всю длину ролика.
- Растворение не может сделать незаметным каждый кадр: быстро движущиеся волны, дым или вспышка огня иногда дают двоение. Превью нужно именно для отбора пригодных клипов.
